# Page 888

A retro teletext-style page for U.S. National Weather Service alerts: no JavaScript, under 50 KB per page, built for old devices and screen readers.

Built for the Kiroween 2026 hackathon (Resurrection category) with Kiro. Specs, steering, hooks and a custom review agent live in [`.kiro/`](.kiro/).

Status: design phase. Requirements, design and tasks are in [`.kiro/specs/page888/`](.kiro/specs/page888/); the generator is not built yet.

Weather data: [api.weather.gov](https://www.weather.gov/documentation/services-web-api). Not an official NWS product.
